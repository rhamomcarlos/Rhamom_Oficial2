# Guia de Estilo Inicial — TechStore

## 1. Identidade Visual

O projeto TechStore utiliza uma identidade visual moderna e simples, buscando facilitar a navegação e proporcionar uma boa experiência ao usuário.

## 2. Regra 60-30-10

## 60% — Cor principal

* **Cor:** Branco
* **HEX:** `#FFFFFF`
* **Uso:** fundo das páginas e áreas maiores.

## 30% — Cor secundária

* **Cor:** Azul escuro
* **HEX:** `#1E3A5F`
* **Uso:** cabeçalho, menus, cards e elementos estruturais.

## 10% — Cor de destaque

* **Cor:** Laranja
* **HEX:** `#FF6B35`
* **Uso:** botões, links importantes e chamadas para ação.

## 3. Tipografia

## Títulos — Poppins

A fonte Poppins foi escolhida para os títulos por apresentar um estilo moderno e ajudar na criação de uma hierarquia visual clara.

## Textos — Roboto

A fonte Roboto foi escolhida para os textos por possuir boa legibilidade e facilitar a leitura em diferentes tamanhos de tela.

## 4. Organização dos Assets

Os arquivos do projeto foram organizados nas seguintes pastas:

* `assets/images` — imagens utilizadas no projeto.
* `assets/icons` — ícones utilizados no projeto.
* `assets/css` — arquivos de estilos CSS.
* `pages` — páginas adicionais do site.

## 5. Conclusão

A identidade visual do TechStore utiliza cores seguindo a regra 60-30-10 e fontes que priorizam modernidade e legibilidade. A organização dos arquivos facilita a manutenção e evolução do projeto.
