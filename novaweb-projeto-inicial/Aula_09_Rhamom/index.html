1. Inline, interno e externo

CSS inline

Este parágrafo recebe CSS pelo atributo style.

<p style="color: #174b32;">Texto</p>

CSS interno

Este parágrafo recebe CSS da tag style no head deste HTML.

<style>
    .exemplo-interno { color: #63300d; }
</style>

CSS externo

Este parágrafo recebe CSS do arquivo estilo.css.

<link rel="stylesheet" href="estilo.css">

O CSS externo pode ser reutilizado em várias páginas. O interno pertence ao documento. O inline pertence ao elemento. A prioridade também depende da cascata e da especificidade; o CSS interno não ganha automaticamente do externo.

2. As quatro partes do box model

Margin — espaço externo
Border — contorno
Padding — espaço interno
Content — conteúdo

Este desenho representa as camadas. No elemento real, a margem é transparente; o fundo se estende pela área de padding.

padding: 10px 20px usa 10px em cima e embaixo, e 20px nas laterais. Em margin: 5px 10px 15px 20px, a ordem é topo, direita, base e esquerda.

3. Card solicitado no PDF

Conteúdo de 300 × 150px, padding de 20px, borda de 1px e margem de 10px.

Etapa do desafio

Cada etapa ocupa uma caixa. O espaço interno protege a leitura, a borda marca o limite e a margem separa as etapas.

Com box-sizing: content-box, a largura até a borda é 300 + 40 + 2 = 342px. Com as duas margens de 10px, o espaço horizontal total é 362px. A altura até a borda é 150 + 40 + 2 = 192px.

.card {
    box-sizing: content-box;
    width: 300px;
    height: 150px;
    padding: 20px;
    border: 1px solid #ccc;
    margin: 10px;
}

Com border-box, width e height incluiriam o conteúdo, o padding e a borda. A margem continuaria externa.

4. Desafio: centralizar o card

As margens laterais automáticas dividem o espaço horizontal disponível.

Etapa em foco

A etapa aparece centralizada graças às margens laterais automáticas, mantendo as medidas do exercício.

.card-centralizado { margin: 10px auto; }

Em telas muito estreitas, as áreas dos cards permitem rolagem horizontal para preservar as medidas do exercício.

5. Aplicação na página pessoal

A página Sobre Mim de Rhamom aplica padding, margens e uma largura máxima centralizada, usando o mesmo CSS externo.
