Sintaxe básica utilizada

function declara uma função. As chaves delimitam seus comandos. const guarda uma referência que não será reatribuída; = atribui um valor. O evento onclick chama a função quando o botão é clicado.

function alterarTexto() {
    const mensagem = document.getElementById("mensagem");
    mensagem.innerHTML = "Desafio concluído: a página respondeu ao clique!";
}
